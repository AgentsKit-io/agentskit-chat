fix: minify the @agentskit/chat bundle so new code fits the size budget

`dist/*.js` of `@agentskit/chat` was at 180752 / 180000 bytes, the budget counted over every emitted ESM file. `dist/index.js` itself is only 2.7 KB; server, protocol, devtools and drizzle-pg code already lives in its own subpath files, so nothing was left to split. The build now uses full esbuild minification with `keepNames` (class and function names stay readable at runtime): 128112 / 180000 (29% headroom), budget unchanged.

Largest modules in the bundle before the change: `src/index.ts` 25.7 KB, `protocol/src/index.ts` 16.9 KB, `server/src/index.ts` 14.7 KB, `protocol/src/deterministic.ts` 12.1 KB, `src/deterministic.ts` 11.6 KB, `server/src/ask-service.ts` 11.2 KB, `src/catalog.ts` 10.1 KB, `src/ask.ts` 10.1 KB, `protocol/src/fixtures.ts` 9.6 KB, `aws4fetch` 9.0 KB.
