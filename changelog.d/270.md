feat: erase all chat data of a tenant in one call (LGPD, RF-08)

`@agentskit/chat/server` exports `eraseTenantChatData({ tenant, sessions, decisions, memory, cost })`. It runs a tenant-scoped eraser you provide for each category, refuses a blank tenant ID, and returns per-category counts. If any eraser fails, it throws `TenantErasureError` naming the failed categories. Retrying is safe. See ADR-0041.
