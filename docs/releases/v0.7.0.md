# AgentsKit Chat 0.7.0

`0.7.0` versions the fixed group `@agentskit/chat` and `@agentskit/chat-cli`.
Protocol v1 and the two-package publication graph remain intact.

## What changed

- `createAskAdapter` no longer defaults to the retired hosted Ask service.
  `AskAdapterOptions.endpoint` is required, and a missing or blank endpoint
  throws a clear error.
- Runtime dependencies follow the current AgentsKit releases:
  `@agentskit/eval ^0.7.0` (previously `^0.4.17`), `@agentskit/memory ^0.12.0`,
  `@agentskit/net ^0.2.3` and `@agentskit/statechart ^0.3.2`. The CLI uses
  `@agentskit/cross-platform ^0.3.0`.
- The Svelte renderer cancels an active stream on config replacement through the
  store's idempotent `destroy()`, so `@agentskit/svelte` 0.6 aborts the old
  source only once.

## Upgrade and compatibility

```bash
npm install @agentskit/chat@0.7.0 @agentskit/core@^1.15.0
npm install --save-dev @agentskit/chat-cli@0.7.0
```

Pass the Ask service URL you deploy, or a same-origin path served by your
backend: `createAskAdapter({ endpoint: '/api/ask', corpus: 'docs' })`.
The `@agentskit/core ^1.15.0` peer floor is unchanged from `0.6.0`.

## Publication handoff

This preparation does not publish packages. Full CI, human release review,
merge and the stable tag remain release-owner responsibilities. No UI
implementation is changed by this release preparation. The tag workflow runs
the complete release matrix before Trusted Publishing.
