# AgentsKit Chat 0.6.0

`0.6.0` versions the fixed group `@agentskit/chat` and `@agentskit/chat-cli`.
Protocol v1 and the two-package publication graph remain intact.

## What changed

- Durable action approval/denial across requests reuses upstream `ToolDecisionStore`.
  An atomic claim admits one execution; repeated decisions replay stored results.
  Optional Drizzle/PostgreSQL decision storage supports multiple server instances.
- Per-turn cost policy reuses upstream `CostStore`: reserve before dispatch,
  settle actual usage afterwards, and charge cancelled dispatched turns using
  actual usage or the reservation when usage is unknown. Quota exhaustion returns
  402 `QUOTA_EXCEEDED`; snapshots expose utilization and warnings.
- Image/file reference parts now reach multimodal adapters through authorized
  fresh signed URLs or bounded bytes. Transcripts retain references only.
  Unsupported adapters return 422 `TURN_PARTS_UNSUPPORTED`.
- Documentation context is generated locally and in CI rather than committed.

## Upgrade and compatibility

```bash
npm install @agentskit/chat@0.6.0 @agentskit/core@^1.15.0
npm install --save-dev @agentskit/chat-cli@0.6.0
```

The core peer floor rises to `^1.15.0`, which breaks compatibility with older
core hosts. Custom `ControlledChatActions.send` implementations must accept
`string | ContentPart[]`. Hosts enabling cost policy must install the optional
`@agentskit/observability >=0.13.0 <1` peer. Decision storage, cost policy and
uploads require explicit host configuration and authorization.

## Publication handoff

This preparation does not publish packages. Full CI, human release review,
merge and the stable tag remain release-owner responsibilities. Human visual
approval is pending; no UI implementation is changed by this release preparation.
The tag workflow runs the complete release matrix before Trusted Publishing.
