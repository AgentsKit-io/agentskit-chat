# AgentsKit Chat 0.5.0

`0.5.0` is an additive minor release of the fixed group: `@agentskit/chat` and
`@agentskit/chat-cli`. The two-package graph and protocol v1 remain intact.

## What changed

- Optional `@agentskit/chat/drizzle-pg` provides tenant-scoped Drizzle/PostgreSQL
  SessionStorage with atomic cursor compare-and-swap. Message memory remains an
  upstream AgentsKit responsibility. See [storage integration](../architecture/adrs/0036-drizzle-postgres-session-storage.md).
- Protocol v1 adds reference-part schemas and capability negotiation fields.
  Hosts can opt into authorized S3-compatible uploads with tenant/session binding,
  size, MIME, and SHA-256 validation. Parts delivery remains unavailable pending
  published upstream support; these fields do not enable unsupported delivery.
- Server callbacks use published AgentsKit Net deadlines, bounded JSON reading,
  and signal composition while retaining request diagnostics.
- Ask requests avoid empty assistant placeholders. Emitted JavaScript is compacted
  within existing bundle budgets while preserving identifiers and exports.
- CLI scaffolding reuses upstream cross-platform rename/remove helpers for Windows
  file-lock recovery. Framework peer ranges support current AgentsKit 0.x bindings.

## Upgrade

Update both packages together:

```bash
npm install @agentskit/chat@0.5.0
npm install --save-dev @agentskit/chat-cli@0.5.0
```

Existing definition-owned and controlled sessions remain supported. Storage and
upload integrations are opt-in; review their host authorization and persistence
requirements before enabling them. Pin the new minor line and run application
conformance and host E2E checks before upgrading.

## Release evidence and publication

This is release preparation, not proof of npm publication. The release owner must
review local gate evidence, run pending CI/native/browser checks, merge the PR,
and create the stable tag. `release.yml` publishes through Trusted Publishing;
registry provenance, checksums, clean-install and host smoke evidence follow publication.
